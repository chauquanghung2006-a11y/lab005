# LAB005 - GoREST API Testing

## Requirements
- Postman
- GoREST API Access Token

## Setup
1. Import the Postman Collection JSON file.
2. Import the Environment JSON file.
3. Select the imported Environment in Postman.
4. Enter your GoREST access token in the `token` variable.
5. Run the Collection using Collection Runner.
6. Review the Passed and Failed test results.

## Test Cases
- Create User
- Get User
- Update User
- Delete Inactive User
- Teardown: Delete All Users
- Create User with Invalid Authentication
- Create User with Duplicate Email
